# DocuCraft MCP Server 📄💼⚡

Universal Autonomous PDF Invoices, Legal Contracts, ATS Resume Optimizer & Document Engine MCP Server for **Cursor, Claude Code, and Windsurf**.

## 🌟 Core Capabilities:
- 🧾 **Print-Ready HTML/PDF Invoices:** Generates beautiful commercial invoices with auto-calculated subtotals, VAT/tax, itemized line tables, and payment instructions.
- ⚖️ **Legal Contract & NDA Engine:** Drafts comprehensive Mutual NDAs, Freelance Service Agreements, and SaaS SLAs with customizable jurisdiction clauses.
- 🎯 **ATS Resume & CV Optimizer:** Scores candidate resumes against target job descriptions, identifies missing high-value keywords, and outputs ATS-compliant markdown resumes.
- 📑 **Executive Markdown Document Styler:** Transforms raw markdown into print-ready executive reports with custom corporate themes and callout boxes.
